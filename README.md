# 👟 متجر أحذية إلكتروني (Shoe Store)

موقع ويب متكامل ومستجيب (Responsive) لمتجر أحذية إلكتروني، مصمم بالكامل باللغة العربية مع واجهة مستخدم مريحة (RTL) وتجربة تصفح انسيابية. يعرض المتجر تشكيلة متنوعة من الأحذية الرياضية والكاجوال مع أقسام خاصة بآراء العملاء ونموذج للتواصل.

---

## 🚀 المميزات (Features)

*   **تصميم متوافق بالكامل (RTL):** الواجهة مصممة هندسياً لتبدأ من اليمين لتناسب تجربة المستخدم العربي بشكل طبيعي ومنطقي.
*   **تجربة تصفح سلسة:** استخدام الـ `scroll-behavior: smooth` للانتقال بين الأقسام بنعومة فائقة.
*   **تجاوب كامل مع الشاشات (Responsive Design):** الموقع متوافق تماماً مع شاشات الموبايل، التابلت، والشاشات المكتبية بفضل الـ Media Queries.
*   **قسم آراء العملاء (Testimonials):** كروت مخصصة لعرض تقييمات العملاء والنجوم الذهبية لزيادة الموثوقية.
*   **فورم تواصل متكامل:** يحتوي على نموذج اتصال أنيق مدمج مع معلومات الدعم الفني والعنوان.
*   **تأثيرات حركية جذابة (Hover Effects):** حركات انسيابية خفيفة عند التمرير على كروت المنتجات وأزرار التنقل والروابط.

---

## 🛠️ التكنولوجيات المستخدمة (Tech Stack)

*   **HTML5:** لبناء هيكل الموقع والأقسام بشكل دلالي (Semantic HTML).
*   **CSS3:** للتنسيق وبناء الـ Layouts المرنة باستخدام `Flexbox` والـ Media Queries للتجاوب.
*   **Google Fonts:** استخدام خطوط متناسقة تخدم التصميم العربي الحديث (مثل خط Poppins / Segoe UI).
